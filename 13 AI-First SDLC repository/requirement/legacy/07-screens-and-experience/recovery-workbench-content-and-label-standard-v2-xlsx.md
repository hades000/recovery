## Rules

| How labels are written |  |
|---|---|
| Applies to every screen and message. |  |
| Rule | Detail |
| Case | Sentence case for every label, heading and button |
| Buttons | A verb for what happens: Approve, Transfer, Record result |
| Field labels | The business term from the glossary, with the unit in brackets: Offer amount (THB) |
| Help text | One sentence that says what to enter or why; no repetition of the label |
| Dates | d MMM yyyy in English; d MMM yyyy in the Buddhist Era in Thai |
| Numbers | Thousands separators; amounts in THB with no decimals unless the field is a rate |
| Thai length | Layouts allow Thai labels to run 30 percent longer than English |
| Terms | Use the glossary term; never the synonyms the glossary lists as not to use |
| Messages | From the error and message standard; never written on a screen by hand |
