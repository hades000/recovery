# Assumptions — INC-007-epic-1-RWB-TE-012 (Technical Specifier)

Revision v4 (spec gate round 3 remediation; earlier versions kept as `assumptions.run1.md` (v1), `assumptions.run2.md` (v2) and `assumptions.run3.md` (v3)). 31 assumptions, ASM-TE012-01 to -31. No question was asked (L-RCV-03; AGENTS.md §10.6). Each assumption is labelled, has a basis and says what changes if it is wrong. Source short names are defined in `spec.md` "Sources cited".

| ASM-TE012-07 | `caseId` and `documentId` in blob names are UUIDs (`recovery_case.id`, `document.id`). | ASM-TE012-08 | Revised in v4. | ASM-TE012-10 | Not-ready and flag-off refusals use `StorageUnavailableException` with reason `NOT_READY`. | `[S]` §12 lists only two caller exceptions; both cases map to 503 MSG-GEN-006 (`[S]` §12, §13). | A third exception type; mapping unchanged. |
| ASM-TE012-11 | Revised in v3.
