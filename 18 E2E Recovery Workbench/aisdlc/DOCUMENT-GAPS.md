# Document gaps found while building Build Sequence v6 orders 1 to 10

This register is for the document owners. It lists each place where the document set (v14, 16 Nov 2026,
and the AISDLC v2 workspace in `17 AI-First SDLC Repository v2`) leaves out something a story needs, or
where two documents disagree. The delivery did **not** edit any document. Every row was handled in this
build as the "How this build proceeded" column says, and should be fixed at source.

## Rules for this register

- **Evidence:** every row has two citations that disagree, or one citation plus the place where the
  answer should be and is not. No row is based on a guess.
- **Blocker = Yes:** no precedence rule and no documented default lets the story go ahead. The story
  then goes ahead on an assumption that is logged and visible in its spec, or it stops.
- **Precedence:**
  1. Client decisions D-RCV-35 and D-RCV-36.
  2. ADR v3.
  3. Decision Log v10.
  4. Epic 1 story files v7.
  5. Older maps and drafts.
- **Where rows come from:** stage agents write candidate gaps to
  `output/<RUN_ID>/<stage>/document-gaps.md`. The orchestrator checks the evidence, numbers each
  confirmed gap here (`DG-nnn`) and keeps the stage's local ID in the "Raised by" column.
