## 1. GAP-1530 (Register gap; ruling R-28637; sections: find it)
- Title: Four P10 features carry the same main success criterion, so the criterion does not distinguish the feature it belongs to
- Detail: The platform set-up, the guardrail checker, the evaluation harness and the rule fallback each carry the same approved-endpoint run criterion, the same prompt-version criterion and the same schema-check criterion, and each also carries the same six exception criteria. One criterion cannot be the evidence of four different features, and a reader cannot tell from the criterion which feature accepts it.
- Evidence: FSD P10 v3 AC-P10-001-01, AC-P10-002-01, AC-P10-005-01 and AC-P10-011-01 are identical in text. AC-ALT-P10-001-01, 002-01, 005-01 and 011-01 are identical. The exception sets of the four features are identical too.
- Proposed fix: The PRD keeps the criteria that are stated once and gives each feature the criterion that shows its own behaviour: the guardrail rejects, the fallback returns the rule result, the harness scores, and the platform set-up produces the run row and the event. The repeated source criteria stay as the shared background.
- Owner role: Business analyst
