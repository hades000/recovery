## 2. GAP-2021 (Register gap; ruling R-28880; sections: find it)
- Title: Child and kit workflow ID format
- Detail: The parent workflow ID is fixed as case-{caseId}. Architecture v5 describes one child workflow per stage and the kit workflows but gives no ID format for either, and no source states whether the case ID prefix is reused or suffixed. The ID is what the UI, the search attributes and the run book of a stage address.
- Evidence: Workflow Engine Design v3 section 5, Workflow IDs: 'case-{caseId} (for example case-RW-2026-000123); platform-smoke-{yyyymmdd}'. Architecture v5 slide 25 names the children but gives no ID. Temporal and Drools Design v1 slide 13 gives none either.
- Proposed fix: The parent generates one ID per child from the case ID and the stage code, so a stage can be found from the case ID alone and a restart of the parent cannot create a second child for the same stage.
- Owner role: Service owner P3 rwb-case
