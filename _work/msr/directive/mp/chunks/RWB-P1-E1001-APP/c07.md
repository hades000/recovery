## 1. GAP-0980 (Register gap; ruling R-28414; sections: find it)
- Title: role.entra_group is a column in the technical specification and not a Workbench column in the functional one
- Detail: TSD P4 v3 T3.1 gives role.entra_group Field ID DF-REF-039, varchar(120), sourced from Entra ID. FSD P4 v3, re-based on the ACE database, states that the Entra group is read from v_ace_iam_group and is not a Workbench column. A column created on one reading is a copy of an ACE fact on the other, which the boundary rule forbids.
- Evidence: The TSD field table lists entra_group under role with DF-REF-039 and source 'Entra ID'; the FSD field catalog says 'v_ace_iam_group.entra_group ... read from ACE (iam_group, RWB-ACE-001); not a Workbench column'
- Proposed fix: Keep the column because the technical specification outranks the functional one in R-PREC, create it nullable and empty, and read the mapping at run time through the rwb-source-data contract so no ACE fact is copied or maintained here.
- Owner role: Solution architect
