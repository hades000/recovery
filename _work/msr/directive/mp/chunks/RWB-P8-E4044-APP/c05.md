## 4. GAP-2521 (Register gap; ruling R-29019; sections: find it)
- Title: proceeds.account_payment_id points at an account_payment object that no owner of the ownership map declares
- Detail: The proceeds schema carries account_payment_id as an optional cross reference and the TSD relationship table names account_payment as its target, many to 0 or 1. - Evidence: TSD P8 v2 T3.1 DF-FIN-004 'account_payment_id / CROSS_REF / uuid / No / None / Workbench'; TSD P8 v2 T3.3 'proceeds / account_payment_id / account_payment / Many to 0 or 1'; context pack P8 tables owned: proceeds only; FSD P8 v3 A2.4 Data table lists v_ace_payment, not account_payment.
- Proposed fix: State in the Logical Data Model and the Service Contract Catalog whether account_payment_id carries the ACE payment code of v_ace_payment and nothing else, and remove the account_payment relationship from TSD P8 T3.3 in its next version if no object is intended.
