64 A10. Refusal and failure model

66 No token, or a session that has ended | 401 | MSG-P4-001 | the user
67 The role holds no letter in the area | 403 | MSG-P4-002 | the user
68 The record is outside the role's scope | 404, and the excluded count is never shown | MSG-P4-003 | the user
69 An approve action above the DoA limit | the action is routed to the approver role named for the limit | - | the user and the approver
