## Summary

The spec is thorough and its technical design matches the binding decisions (D-RCV-03/-05/-12/-17/-18/-28/-34,
OPEN-007/-013/-014 rulings) and the ACE code as it stands on eedf5c75. The PO answers to CLAR-001 and
CLAR-002 are recorded faithfully. Two gaps block the handoff: the container comparison that the PO accepted
in place of BR7 "runs in the build" according to the question put to the PO, but the spec puts it in a task
that nothing in CI runs; and the recovery Flyway activation rule also matches the existing core `db-migrate`
Jenkins step in SIT/UAT/PROD, so what happens there is left to a side effect.
