## How it applies

| How the matrix is applied |  |
|---|---|
| Rules the Workbench applies when it routes an approval. |  |
|  | Rule |
| 1 | The limit is set on the borrower's principal outstanding, or on fair market value for assets held for sale |
| 2 | A limit that depends on collateral value needs a fair market value appraisal by an independent valuer within the last year |
| 3 | Where a level has two rows, the approval is within limit if either row is met |
| 4 | A second delay of legal action or of an auction goes one level up |
| 5 | New credit to a problem loan takes the higher of the restructuring authority and the credit authority in the credit approval regulation |
| 6 | A write-off for a director, senior executive, major shareholder or related party goes to the Board |
| 7 | Hire purchase, auto and unsecured loans follow chapter 8 of the credit approval regulation รบ.-กส.450032 as amended by กกค.690085. Those limits load when supplied (DL18) |
| 8 | A decision that no limit covers goes to the next level up, and an incident records the missing limit |
| 9 | A decision keeps the matrix version it was approved under |
| 10 | A person may not approve a decision they proposed or prepared |
| 11 | Each limit is a row in the delegation limit table with a version, valid from and valid to dates and the approver of the change. A change is a data load approved by Risk |

## Key

| Key |  |  |
|---|---|---|
| What each term means. |  |  |
