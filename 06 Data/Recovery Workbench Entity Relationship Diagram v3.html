IDEF1X notation

The diagrams use the IDEF1X notation for entities, keys and relationships.

SymbolMeaning
Square-cornered boxAn independent entity. Its key does not depend on any other entity. Every entity in this model is independent
Name above the boxThe entity name as it is held in the ACE database
Line inside the boxAbove the line is the primary key. Below it are the other attributes
(FK)A foreign key: a reference to another entity
(AK1)An alternate key: unique on its own or together with the other AK1 attributes of the entity
Dashed lineA non-identifying relationship. The child refers to the parent, and the child's key does not include it
Filled dotThe child end of the relationship: zero, one or more child records
Open diamondAt the parent end: the reference is optional, so a child may have no parent
No diamondAt the parent end: the reference is mandatory, so every child has exactly one parent
Label on the lineThe foreign key attribute that carries the relationship
Dashed grey boxAn entity from another data product, shown with its key only
