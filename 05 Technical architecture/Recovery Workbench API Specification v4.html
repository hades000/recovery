Rules every endpoint follows

RuleDetail
Sign-inBearer token from Entra ID through the ACE front end; partners through the external gateway (DL03)
AccessThe endpoint declares its capability area and right; scope filters every query; out of scope returns 404
ApprovalsApproval endpoints check the approval level, the delegation of authority limit and maker and checker
Decision logEvery state change writes its decision log entry first; a failed write returns 503 and nothing changes
ConcurrencyRecords carry a version; a stale version returns 409 with MSG-GEN-004
IdempotencyPOST requests carry an Idempotency-Key header; a repeat returns the first result
Pagingpage and size query parameters; size up to 100
DatesISO 8601; dates in the Asia/Bangkok business day
Personal dataFields marked x-personal-data are masked unless the role may see them
Errorsapplication/problem+json with the message code and the Thai and English text from the error and message standard
